; Spiritwood — "Forest_Night" level source.
; Build: node tools/level/build-level.ts   →   public/levels/forest.ldtk (LDtk 1.5.3)
; Preview: node tools/level/preview-level.ts <out.png> [--scale 6] [--crop x0,x1]
; Masses:  node tools/level/masses.ts   worst camera views by solid interior deeper than 3 tiles (the part
;          that renders as deep rock); tests/level/forest.test.ts keeps every view under 8 %. Carve instead:
;          ledges, alcoves, thin scenery rock (≤ 5–6 tiles) and open air where the forest shows through.
; Launch course: node tools/level/analysis.ts   the closure bounds, the shrine chokepoint closure and stream
;          fairness (§5.4).
;
; Sections
;   [level]     key = value (id, seed)
;   [entities]  one entity per line; numbers are in tiles (1 tile = 48 u), x y = top-left cell
;   [map]       260 × 50 tile rows, top row first
;
; Map glyphs (tiles: the ASCII_TILES legend of src/level/ascii.ts)
;   #  Solid        =  OneWay (solid from above; down + jump drops through)        ^  Thorns
;   .  empty
;   P  player start (feet at the cell's bottom-centre)     o  orb (cell centre, value 1)
;   L  lantern hint (anchor at the cell's bottom-centre)   f  flora hint (feet at the cell's bottom-centre)
;
; [entities]
;   Checkpoint x y w h                        respawn point = the rect's bottom-centre
;   Goal       x y w h                        the Moonwell shrine
;   Enemy      x y w speed                    Gloomcrawler: patrol rect w cells wide on row y (feet on its
;                                             bottom edge), spawning at its centre; speed in u/s
;   Spitter    x y aim [key=value …]          Thorn Spitter, feet at the bottom-centre of cell (x, y); aim is
;                                             player or fixed. Keys (defaults: WorldTuning spitterDefault*):
;                                             angle (deg from +x toward screen-up, fixed aim only, 90),
;                                             speed (u/s, fixed aim only), range (u), period, phase,
;                                             flight (flightTicks of a player-aimed shot)
;   AbilityShrine x y w h [ability]           the rect that unlocks `ability` (launch) on first touch
;   LightShaft x y w h angleDeg spread intensity   top aperture x, y, w; vertical length h
;   GradeZone  x y w h grade blendCells       grade: glade | gully | rootwell | canopy | veil | shrine
; Entity ids follow the order of lines (checkpoints, crawlers, spitters, …) and of glyphs (orbs, row by row).
; LevelData lists every crawler, then every spitter.
